# 소예뷰티 아카데미 홈페이지

경기도 용인시 기흥구 보정동에 위치한 **소예뷰티 아카데미**의 공식 홈페이지입니다.  
반영구 화장 전문 스튜디오 & 아카데미를 소개하는 단일 페이지(SPA) 정적 웹사이트입니다.

---

## 프로젝트 구조

```
SoyeHome/
├── index.html      # 메인 HTML (전체 섹션 포함)
├── styles.css      # 전체 스타일 (반응형 포함)
├── script.js       # 인터랙션 로직
└── images/         # 프로필·갤러리 이미지
```

## 주요 기능

- **스티키 헤더** — 스크롤 시 헤더 스타일 변경
- **모바일 햄버거 메뉴** — 반응형 네비게이션
- **스크롤 활성 네비게이션** — 현재 섹션에 맞는 메뉴 하이라이트
- **갤러리 필터** — 카테고리별 시술 사진 필터링
- **FAQ 아코디언** — 자주 묻는 질문 토글
- **스크롤 리빌 애니메이션** — IntersectionObserver 기반 요소 등장 효과
- **맨 위로 버튼** — 스크롤 위치에 따른 노출

## 섹션 구성

| 섹션 | 내용 |
|------|------|
| `#home` | 히어로 — 원장 사진, 연락처, CTA 버튼 |
| `#about` | 원장 소개 — 김소예 원장 경력 및 자격 |
| `#services` | 시술 안내 — 눈썹·입술·헤어라인·아이라인·속눈썹·SMP |
| `#academy` | 아카데미 — 교육 과정 및 수강 안내 |
| `#gallery` | 갤러리 — 시술 전후 사진 (카테고리 필터) |
| `#interior` | 인테리어 — 샵 내부 사진 |
| `#booking` | 예약 — 네이버 예약·카카오 채널·전화 예약 |

## 기술 스택

- Google Fonts (Cormorant Garamond, Nanum Myeongjo, Noto Sans KR)
- Font Awesome 6.5.1
- Schema.org 구조화 데이터 (LocalBusiness)
